# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Use GitHub private
vulnerability reporting (Security > Report a vulnerability) on the affected
repository, or contact the maintainer listed in the repository.

Include: affected component and version, a description, reproduction steps, and
any proof of concept.

## Scope

- Control-plane authentication, pairing and TLS.
- Remote-session credential handling and certificate pinning.
- Wake-on-LAN packet handling.

## Handling

We aim to acknowledge within a few days, provide a fix or mitigation, and
coordinate disclosure. Supported versions are the latest release of each
repository.
