# ADR-0002: Project name `twinelink`

- Status: accepted

## Context

"KDE Connect" ties the product to the KDE desktop and does not convey remote
control, Wake-on-LAN, or the broader device-link idea. The word "Twine" was
disliked for being saturated in software (PyPA `twine`, twinery.org).

## Decision

Product and identifier: **`twinelink`**. Repos are prefixed
`twinelink-*`. The protocol identifiers stay `kdeconnect.*` regardless of name
(C-10).

## Consequences

- Distinct from existing software; easy to search.
- Slightly less elegant than a bare word, acceptable for clarity.
- A collision pass (domains, registries, trademark) runs in M0 (R-7).
